# 🎯 Interactive Brokers Algo Bandit Optimizer

An interactive web application running a client-side Bayesian Multi-Armed Bandit engine (via Thompson Sampling) to optimize execution pathways among Interactive Brokers fill algorithms.

### 🚀 Live Application
Launch the tool instantly in your browser here: 
https://jrinne314.github.io/ib-bandit-trade-optimizer/
